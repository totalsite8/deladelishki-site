# Prompt: концепции общей дизайн-системы без дизайна всех страниц

```text
Прочитай @AGENTS.md, существующие global styles/layout/components и утверждённый product brief. Ничего не меняй.

Предложи 2–3 направления общей брендовой системы deladelishki.ru уровня premium 2026. Это не page concept: система должна объединять разные характеры страниц — cinematic home/services, calm blog, tool-like prompts, editorial photography, data-led analytics.

Для каждого варианта:
- ощущение бренда;
- dark/light canvas strategy;
- core + domain accent logic;
- typography direction с self-hosted variable/static font trade-off;
- spacing/geometry/radius;
- navigation language;
- image/video treatment;
- motion vocabulary (durations/easings/springs);
- focus/accessibility;
- как выглядит на 320px и ultrawide;
- что остаётся одинаковым и что меняется по страницам;
- assets/licenses needed;
- implementation complexity/performance.

Не называй конкретный платный шрифт окончательным без проверки лицензии. Не подключай Google Fonts/CDN. Не генерируй final colors без contrast check.

Сравни варианты по premium feel, distinctiveness, readability in Russian, flexibility, accessibility, performance. Рекомендуй один и остановись до выбора. Код не писать.
```
