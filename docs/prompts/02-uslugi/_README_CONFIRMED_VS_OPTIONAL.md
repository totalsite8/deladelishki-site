# Confirmed services vs optional topics

Danila's supplied hierarchy is authoritative and remains the navigation/content priority.

Files whose first heading is `Recommended service prompt` are **not approved top-priority services and not automatic published routes**. They exist only to help evaluate whether a useful business topic should become:

1. a section/interactive child item inside its confirmed parent page — preferred first;
2. an article/course/prompt;
3. a future service route only after enough unique content, real demand and no SEO cannibalisation.

Kimi must not add recommended items to main navigation, sitemap or published pages merely because a prompt exists.
