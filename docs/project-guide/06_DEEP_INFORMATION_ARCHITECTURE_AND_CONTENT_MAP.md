# Глубинная структура сайта и карта контента

Статусы:

- **C — confirmed:** раздел задан владельцем.
- **R — recommended:** профессионально полезное расширение из опыта/резюме; публиковать после утверждения.
- **U — utility:** служебная/доверительная страница.

Owner decision: исходный список услуг остаётся основой. Recommended leadership topics ниже не являются приоритетом и не добавляются автоматически в main navigation. Сначала они могут быть sections/interactive child topics внутри подтверждённых родительских страниц; отдельный route появляется только после content/SEO решения.

## Locale layer

Первый релиз: RU + EN. Recommended mapping: Russian default without prefix; English under `/en/` with localized English slugs tied to stable route IDs. Language switch must preserve the same content entity, not send every switch to home. Only human-reviewed published translations enter sitemap/hreflang.

Header не должен показывать 11 равных пунктов. Рекомендуемый desktop header:

```text
Услуги | Кейсы | Блог | База промптов | О нас | [Обсудить проект]
```

Остальное — mega-menu/«Ещё», поиск и footer. На mobile — доступный drawer/accordion.

# 13. SEO/schema map

| Страница | Основная schema |
|---|---|
| Главная | `WebSite`, `Person`; `SearchAction` только после рабочего поиска |
| Service hub/detail | `Service`, `BreadcrumbList`, provider `Person` |
| Blog hub | `Blog`/`CollectionPage` |
| Article | `Article` или `NewsArticle`, `BreadcrumbList`, author `Person` |
| Review | `Review` только при реальном review и корректном `itemReviewed` |
| Prompt hub | `CollectionPage`/`ItemList` |
| Prompt detail | `CreativeWork` |
| Course hub | `CollectionPage`/`ItemList` |
| Course detail | `Course`; offer только при реальных price/currency/availability |
| Agent skill | `TechArticle`, `SoftwareSourceCode` только если есть реальный код |
| Apps | `SoftwareApplication` |
| Cases | `Article`/`CreativeWork`; не `Review` без отзыва |
| О нас | `AboutPage`; `Organization` only after factual/legal decision |
| Данила/real team member | `ProfilePage` + `Person` |
| Contacts | `ContactPage` + contact data |
| Search | `SearchResultsPage` |
| 404 | noindex, обычная `WebPage` или без отдельной schema |

Schema не гарантирует rich result. Добавлять только видимые и реальные данные.
